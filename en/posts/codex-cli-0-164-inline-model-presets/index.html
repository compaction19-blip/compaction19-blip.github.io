At a Glance

  • According to the official changelog dated 2026-10-23, starting with Codex CLI 0.164.0, you can specify the model, reasoning effort, and speed on a single line after /model. You can specify a permissions profile on a single line after /permissions.
  • Frequently used prompts and slash commands (commands that start with /) can be saved in /presets, which has 10 numbered slots. Saved items are recalled through a keyboard-operated menu.
  • On our Windows PC, we only completed installation, checked the version, and reached the login screen. Because we stopped at the login stage, we have not actually used the new features yet. The verification level is partial.

What to Check Before You Start

  • Pricing and accounts: We did not pay to install the Codex CLI package. However, authentication (sign-in) is required to use it. The official authentication documentation states: "Sign in with ChatGPT for subscription access; Sign in with an API key for usage-based access". If you use an API key, standard OpenAI Platform API rates apply, and those charges are calculated separately from the usage included in your ChatGPT plan.
  • The login instructions displayed in the application said that usage is included in the Plus, Pro, Business, and Enterprise plans. Exact monthly prices, limits, available models, and speeds vary by plan and workspace, so you need to check them yourself.
  • Requirements: You need a terminal (a window where you type text commands) with Node.js and npm (a tool for downloading and installing JavaScript programs). Our test environment was Windows, Node v26.5.0, and npm 11.17.0. The package specifies Node 16 or later, but we did not test older versions.
  • Operating system: The official installation guide provides separate options for macOS/Linux, Windows, npm, and Homebrew. On Windows, we only checked the version, help output, and sign-in selection screen. We did not verify features available after sign-in, WSL, or the minimum Windows version.

Installation

Official Documentation Method (📄 Based on the Official Docs; Not Run This Time)

1. 📄 Install a specific version.

npm install -g @openai/codex@0.164.0
  • Success indicator: The official changelog does not include the exact installation completion message. Check the version in the next step.

2. 📄 Check the version.

codex --version
  • Success indicator: The CLI version is printed, and its value is 0.164.0.

3. 📄 Run codex in your project folder. If this is your first time, choose Sign in with ChatGPT.

  • Success indicator: A browser window opens. After you sign in, the browser passes the authentication information back to Codex.

What We Actually Did (✅ Tested Directly, Isolated Installation)

To avoid changing system-wide settings, we installed it in a single empty folder rather than using -g (a global installation, available across the computer).

1. ✅ Create an empty working folder in PowerShell and move into it. 2. ✅ Apply settings that are used only in the currently open PowerShell window. Then create the codex-home folder and the temp folder. Do not change system environment variables. These settings disappear when you close the window, so when using a new window, return to the same folder and run the commands below again first. Otherwise, the CLI may use a different settings folder, making it look as though you are not signed in or have no saved settings.

$env:CODEX_HOME="$PWD\codex-home"; $env:npm_config_cache="$PWD\npm-cache"; $env:TEMP="$PWD\temp"; $env:TMP=$env:TEMP

3. ✅ Install the package.

npm install --prefix . --no-audit --no-fund --ignore-scripts @openai/codex@0.164.0
  • Success indicator: exit 0 (normal completion) and 2 packages added. In our single run on this PC, it took 19.885 seconds.

4. ✅ Check the version.

node .\node_modules\@openai\codex\bin\codex.js --version
  • Success indicator: codex-cli 0.164.0
  • If you get stuck: .\node_modules\.bin\codex.cmd --version failed with "The system cannot find the path specified" (지정된 경로를 찾을 수 없습니다) (exit 3). We therefore ran it directly with node, as shown in the command above.

5. ✅ Launch the application.

node .\node_modules\@openai\codex\bin\codex.js --no-daemon --no-alt-screen --sandbox read-only
  • Success indicator: v0.164.0 appears, along with an authentication selection screen offering ChatGPT / Device Code / API key / Bedrock. We exited here with Ctrl+C.

How to Use It

All the steps below require signing in, so we could not run them this time. They are all based on the 📄 official documentation.

1. 📄 Existing menu method: Type /model in the input field and press Enter.

  • Success indicator: A selection popup opens, showing only the models available to your account and workspace.

2. 📄 Choose a model that actually appears in the popup. The official examples are gpt-6-luna and gpt-6.1-sol.

  • Success indicator: The new model appears in the conversation history. Check again with /status.

3. 📄 New one-line method (PR #54378):

/model [model] --reasoning <level> --speed <tier>
  • The square brackets and angle brackets indicate placeholders; do not type them literally. Both space-separated syntax and the = format are supported. If you omit the model name, only the settings for the current model change.
  • The CLI validates that the model, reasoning effort, and speed are supported, and applies the settings after the server accepts them. Only the current conversation (session) changes; saved defaults remain unchanged.
  • We could not find the allowed values for <level> and <tier> or complete command examples in the official changelog or CLI reference, and we have not run them ourselves. Check PR #54378 and the documentation for the version you use.

4. 📄 One-line permissions settings (PR #54383): The syntax is /permissions <profile-id>, with an actual profile-id.

/permissions :read-only
  • An additional permissions policy confirmation dialog may appear. This feature does not bypass full-access confirmation, feature restrictions, or Windows sandbox setup.

5. 📄 /presets (PR #54380): There are 10 numbered slots and an editor. You are asked to confirm before replacing or clearing a slot. You can create a preset from the text you are currently typing or from the current model, reasoning, and speed settings, and it is saved in the tui.presets configuration.

  • We have not verified the exact keyboard shortcuts or whether presets persist into new conversations, so we are not listing those details.

Common Sticking Points

  • If codex.cmd produces a path error: Run it directly with node .\node_modules\@openai\codex\bin\codex.js. We could not determine the cause of the error.
  • If you see Not logged in: Even though we were signed in to ChatGPT in the browser, that sign-in did not carry over to the CLI using a new settings folder (CODEX_HOME). You need to authenticate separately in the CLI.
  • If you are looking for the Windows installation command: In our automated browser, selecting Windows on the official page did not change the displayed content, so we could not expand the Windows-specific commands. Open the official installation guide yourself to check.
  • If you copied the syntax literally: Replace placeholders such as [model] and <level> with actual values.
