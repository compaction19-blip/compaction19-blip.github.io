At a Glance

  • Starting with 0.163.0, Codex CLI (OpenAI's AI coding tool for the terminal) lets you search settings with /config and change supported settings directly.
  • /keymap lets you change the leader key—the key that starts a shortcut sequence. The default is Ctrl+X.
  • On one Windows PC, we tested settings search, toggling settings on and off, changing the leader key, and restoring the defaults. Because we verified only some features, the verification level is partial (partially verified).

Before You Start

  • Release date: According to the official GitHub release, it was released on 2026-10-15 at 21:30 (UTC). In Korea Standard Time, that is 2026-10-16 at 6:30 a.m.
  • Operating system (OS): The official documentation provides installation instructions for Windows, macOS, and Linux. We tested it on just one Windows x64 PC.
  • Installation options: You can choose npm (a tool for downloading Node.js programs), Homebrew, or a standalone installer (official README). Node.js is required only when installing through npm. The 0.163.0 npm package requires Node.js 16 or later.
  • Cost: The program is open source under Apache-2.0, so installation is free. AI usage costs are separate, however. According to OpenAI Help, Codex is included in ChatGPT plans, including Free and Go, with different usage limits for each plan.
  • Account: You can sign in with your ChatGPT account. An API key is not required. If you sign in with an API key, you are billed separately at standard OpenAI Platform rates (official authentication documentation).

Installation

Method A: Global installation from the official documentation 📄 Based on the official documentation (not run in this test)

1. Enter the following command in a terminal where npm is available.

   npm install -g @openai/codex@0.163.0

2. Check the version.

   codex --version
  • Success check: The output should show version 0.163.0.

Method B: The local folder installation we used ✅ Tested firsthand

We installed the program only in an empty test folder. Installing it inside a folder does not isolate its settings. To avoid touching our existing settings, we pointed CODEX_HOME, SQLITE_HOME, and TEMP to this test folder before running it. This method does not require administrator privileges.

1. Create an empty folder in PowerShell and use cd to enter it. 2. Install only in that folder.

   npm install --prefix . --no-audit --no-fund @openai/codex@0.163.0
  • Success check: You should see added 2 packages. On our PC, this single command took 21.072 seconds.

3. To run it, you would normally use .\node_modules\.bin\codex.cmd --version (check the version) and .\node_modules\.bin\codex.cmd with no options (open the chat interface).

  • If you get stuck: On our PC, this codex.cmd wrapper (a small executable that launches the actual program) failed with a path error. Running the installed codex.exe directly, as shown below, worked.
   $codex = Get-ChildItem .\node_modules\@openai\codex-win32-x64 -Recurse -Filter codex.exe | Select-Object -First 1 -ExpandProperty FullName
   & $codex --version
   & $codex
  • Success check: The output shows codex-cli 0.163.0.

4. If a sign-in prompt appears on the first launch, sign in with your own ChatGPT account. 📄 Based on the official documentation

  • We reused login credentials already on the PC, so we did not sign in again for this test.

How to Use It

Search settings with /config ✅ Tested firsthand

1. Type /config in the chat input and press Enter.

  • Success check: The Configuration menu opens, showing the Appearance, Notifications, Input, Sessions, and Text selection tabs.
  • If you get stuck: When we automatically entered the command and Enter together, the menu did not open. Pressing Enter once more, separately, opened it.

2. Use the left and right arrow keys to switch tabs, or press / and enter a keyword such as tips.

  • Success check: The list narrows to a single item: Tips.

3. Press Enter to toggle Tips between On and Off. Changes are saved automatically, with no separate save step.

  • Success check: Off appears on screen, and show_tooltips=false is saved in the settings file config.toml.

4. For settings that display a restart-required notice, restart as instructed. 📄 Based on the official documentation

Change the leader key with /keymap ✅ Tested firsthand

1. Press Esc to close the settings menu, then enter /keymap.

  • Success check: The screen shows 153 actions, 0 customized, 6 unbound, and Leader shows ctrl-x.

2. Search for leader, press Enter, select Replace binding, and press the key you want to use. We pressed Ctrl+B.

  • Success check: Leader changes to ctrl-b, and Customized (1) appears.

3. After testing, select Remove custom binding, or delete only the newly added tui.keymap.global.leader line from config.toml in the isolated settings folder to restore the default.

  • Success check: Leader is back to ctrl-x, and Customized (0) appears.

Our Hands-On Results

The verification level is partial (partially verified).

  • ✅ We saw the tabs in /config and verified / search, toggling Tips on and off, and automatic saving. Afterward, we restored Tips to On.
  • ✅ In /keymap, we verified changing the leader key from Ctrl+X to Ctrl+B and restoring the default.
  • ✅ Searching for mute in /keymap showed f9 for Toggle Voice Mute.
  • ❌ We did not test whether F9 actually mutes audio. We did not enable voice features or the microphone.
  • ❌ The claim that shortcut hints stay visible when you press the leader key appears only in the release notes. We tried sending Ctrl+X automatically but could not confirm that hints appeared on screen. We had no evidence to distinguish an issue with automated input from a problem with the feature itself, so we did not conclude that it was broken.
  • ❌ Our original plan was to compare the time required with the method of opening and editing config.toml directly. We did not complete this comparison or record the screen. We therefore make no claims about saving a certain number of seconds. All we have left are four screenshots.

Something else differed from our expectations. Installation itself finished quickly, but the codex.cmd wrapper failed, so we spent time finding the executable's path.

Common Sticking Points

  • codex.cmd returns a path error: As in installation step 3 above, try running codex.exe directly from the codex-win32-x64 folder. We did not need to change the system PATH (the list of paths used to find programs).
  • /config does not open the menu: Try pressing Enter once more.
  • An Unknown feature flag error appears: We saw this error after adding --disable app_server_daemon to the launch options. Removing this option allowed the program to run normally.
  • 0.163.0 is missing from the official changelog: Opening the changelog on developers.openai.com redirected us to another changelog page, which had no 0.163.0 entry when we checked. Use the GitHub release page to verify the version details.
  • It is easy to assume "all settings can be changed immediately": The official description says that only supported settings can be changed directly. Settings that require a restart are marked separately on screen.

We should also note this experiment's limitations. These results come from a single test on one Windows PC; we did not test macOS or Linux. We plan to collect the original measurement records and screenshots in one place at AI Lab Notes. The short video is available on YouTube Shorts.

Wrap-Up

Instead of opening a settings file and looking up each setting name, you can now search with /config inside a Codex session and toggle settings directly. We could also change the leader key with just a few keystrokes in /keymap. We have not yet verified shortcut hints or F9 muting firsthand, so we will test those again next time.
