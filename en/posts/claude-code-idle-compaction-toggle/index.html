Claude Code Compacts Automatically While You’re Away

At a Glance

  • Claude Code is a coding assistant made by Anthropic. You use it in a 'terminal'—a text-based command window. Idle compaction was introduced in v2.1.299. If a conversation with more than 200,000 tokens sits idle for about 54 minutes, it is automatically compacted before its 1-hour prompt cache expires. Tokens are the units AI uses to count text.
  • Starting with v2.1.302, you can turn this feature on or off in the /config screen. On our PC (v2.1.303), it was already on (true) without us configuring anything.
  • When we turned the switch off, "idleCompaction": false was saved to settings.json within 0.2 seconds. However, we could not reproduce an actual compaction event.

The official release notes say: "a 200K+ token conversation left idle for about 54 minutes is compacted before its one-hour prompt cache expires, so your next message doesn't reprocess it all." In plain English, compacting the conversation in advance means your next message after returning does not have to reprocess the entire long conversation from scratch. The prompt cache temporarily stores that conversation.

Before You Start

  • Plan and account: You need a Claude Pro, Max, Team, Enterprise, or Console(API) account. It is not available on the free claude.ai plan (official setup documentation). Idle compaction is not a separately paid feature. Compaction counts toward your account’s usage as usual. It does not increase your usage limits.
  • Operating system: You need Windows 10 1809 or later, macOS 13 or later, Ubuntu 20.04 or later, Debian 10 or later, or Alpine 3.19 or later. You also need at least 4GB of RAM and an internet connection.
  • Version: Idle compaction requires 2.1.299 or later. Turning it on or off in /config requires 2.1.302 or later.
  • Where it applies: It works only in the terminal. It runs when a conversation at or above the token threshold (200,000 by default) has been left idle for about 54 minutes. You can change the threshold, and all the conditions under “Understand the Defaults” below must also be met.
  • Caution: Compaction shortens the earlier conversation, so some details may be lost.

Installation

1. Install Claude Code 📄 Based on official documentation

If it is already installed, skip to step 2. Paste the appropriate command for your computer into the terminal.

Windows PowerShell: irm https://claude.ai/install.ps1 | iex
Windows CMD: curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
macOS, Linux, WSL: curl -fsSL https://claude.ai/install.sh | bash
  • If the prompt starts with PS C:\, you are in PowerShell. If it starts with C:\ without PS, you are in CMD.
  • No progress indicator appears during the download. It has not frozen. Once installation is complete, open a new terminal window.

2. Check the Version ✅ Tested hands-on

claude --version
  • Success: You should see a version such as 2.1.303 (Claude Code). It appeared within 1 second on our PC.
  • If you run into trouble: We initially got an error saying the 'claude' command could not be found. That was because Claude Code on our PC was installed separately inside a project folder rather than system-wide. As a result, it was not registered in PATH, the list of locations searched for commands. Running it using the full path to its installed location resolved the issue.

3. Update If Your Version Is Too Old 📄 Based on official documentation

claude update
  • If you already have the latest version, you will see Claude Code is up to date (<version>).
  • If you installed it with WinGet, use winget upgrade Anthropic.ClaudeCode. If you installed it with Homebrew, use brew upgrade claude-code. These two installation methods do not update automatically.

How to Use It

1. Run It from Your Project Folder ✅ Tested hands-on

cd path/to/your/project   (replace with the path to the project folder you will actually work in)
claude
  • On our PC, the input prompt appeared in 4.0 seconds. The version, model, and plan (Claude Max) were also displayed.
  • If this is your first time opening the folder, a screen asks whether you trust it. Select Yes, I trust this folder.

2. Understand the Defaults 📄 Based on official documentation + ✅ Checked on our PC

According to the settings documentation, idle compaction is enabled by default. It runs when all the following conditions are met.

  • You are chatting in the terminal.
  • You are using a 1-hour prompt cache.
  • Feature configuration can be retrieved from Anthropic’s servers.
  • The conversation has reached or exceeded the token threshold (200,000 by default).
  • About 54 minutes have passed since the last request, and the computer is awake at that point.

The documentation says Compacted while idle, before the prompt cache expired appears in the conversation when compaction occurs.

3. Turn It On or Off in /config ✅ Tested hands-on

1. Type /config into the input prompt and press Enter. The settings screen opened within 2.5 seconds. Idle compaction true appeared directly below Auto-compact. 2. The settings list is long. Type idle, and within 1 second only the Idle compaction row remains. 3. Use the ↓ key to select that row, then press Space (or Enter). true means on, and false means off. 4. When you are done, press Esc to close the screen.

Official GitHub release page for v2.1.302 (1.8× zoom): 'released this Sat, Oct 17, 2026' (Korea time), with the 'Idle compaction row added to /config' line highlighted in yellow (video capture)

4. Check That the Setting Was Saved ✅ Tested hands-on

Open %USERPROFILE%\.claude\settings.json in your user folder. Turning the feature off saves "idleCompaction": false, and turning it back on saves true. On our PC, the file reflected the change within 0.2 seconds.

The /config screen from Claude Code v2.1.303 actually running on this PC. The screen text captured through a virtual terminal was reproduced exactly in a large-text terminal-style window (not a pixel screenshot of the window). 'Idle compaction true' is highlighted (video capture)

5. Change the Token Threshold (Optional) 📄 Based on official documentation

The default threshold is 200,000 tokens. To change it, use the CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS environment variable. The official documentation does not give a separate recommended value beyond the default. It states that this environment variable and the settings.json setting work in v2.1.290 or later. To change the setting through the interface, using 2.1.302 or later is the safer choice.

Our Hands-On Results

Verification level: partial

  • On 2026-10-20, we ran v2.1.303 on a Windows PC in a separate practice folder. We did not send any questions to the model.
  • We confirmed the default value, true, in the settings screen. Pressing Space once changed it to false and also saved false to settings.json. Pressing it again changed it back to true.
  • Afterward, we restored settings.json from a backup of the original file. We also verified that it matched the original byte for byte.

Where We Ran into Trouble

  • When we first entered claude --version, the command could not be found because of the PATH issue.
  • The terminal automation tool did not pass through the Enter key. We switched to a different virtual terminal method to continue.
  • We could not reproduce actual idle compaction. Creating a conversation with more than 200,000 tokens and waiting 54 minutes was beyond the scope of this test. The statement that compaction happens after '54 minutes' therefore comes from the official CHANGELOG.

Common Problems

  • It says 'claude' cannot be found: If you have just installed it, try opening a new terminal window. If, like us, you installed it separately inside a folder, run it using the full path to its installed location.
  • There is no Idle compaction row in /config: Check whether your version is older than 2.1.302, then run claude update.
  • /config does not open: It does not open in the VS Code chat panel or the desktop app. Run it in the terminal.
  • Earlier context became less clear after compaction: Some details may be lost during compaction. If needed, turn it off using the steps above.

Summary

If you often step away during long tasks, leaving idle compaction enabled seems reasonable. If you need to preserve detailed context, you can turn it off in /config. These findings come from a single test on one PC. We did not verify an actual compaction event. You can read the source in the official CHANGELOG, and we also posted our verification process as a Short.
