At a Glance

  • What it is: NVIDIA's SkillSpector looks for warning signs before you install agent skills—bundles of additional capabilities for AI coding tools. Results include a risk score from 0 to 100 and a list of findings.
  • Our results: Our verification level is partial (only partially verified). We downloaded the official v2.13.2 file and verified that its hash matched. However, dependency installation failed because our environment had no internet access, and we never managed to run a scan.
  • Quick advice: The score is not a safety certification. Use it only as an initial review tool, and open the flagged lines to inspect them yourself.

Before You Begin

  • Cost: It is open source under Apache-2.0. Static analysis—examining code without executing it—does not itself require a license fee or a personal API key. That does not mean external LLM usage, existing subscriptions, or network access are also free.
  • Accounts and keys: --no-llm lets you run static analysis alone without logging in or providing a key. For LLM analysis, the documentation lists existing CLI logins (claude_cli·gemini_cli·opencode_cli) and a local Ollama option in addition to API keys. codex_cli is registered but currently inactive. We did not use these options in this test.
  • Python: The pinned v2.13.2 release requires Python 3.12 or later, but below 3.15. The main branch lists an upper limit of below 3.16, so do not mix up the two requirements.
  • OS: The package is declared OS Independent. However, according to the README, --output file output is unavailable on Windows. We could not verify whether scans actually run on Windows.
  • Network: You need internet access to download dependencies. Even with --no-llm, it queries OSV.dev for dependency names and versions. If it cannot connect, it falls back to a small built-in list, so this is not an option that eliminates all network communication.

Installation

This time, instead of uv tool install, we chose to install the official wheel (a Python installation package) in an isolated venv (a project-specific virtual environment). Installing from the Git URL would not pin it to a specific release and would place it in the user's shared tools area. We did not use administrator privileges, a global installation, or execution policy changes.

1. Check the Python version ✅ Tested firsthand

  • Our environment was Windows / Python 3.13.12.
  • Success criterion: the version is within 3.12–3.14.

2. Create a venv in an isolated folder ✅ Tested firsthand

  • In PowerShell (the Windows command shell), navigate to your working folder and run the command. Be careful not to overwrite another project's venv.
   python -m venv .venv
  • Success criterion: exit code 0. No output is normal. It took us 11.630 seconds.

3. Download the official wheel and compare its hash ✅ Tested firsthand

  • Download skillspector-2.13.2-py3-none-any.whl from the v2.13.2 release page into the same folder.
  • Success criterion: the SHA256 value (the file's fingerprint) matches the one below. Ours matched.
   82bd8e468229c949cd178edce058fceb95c415fd845ba924f56e7160c8b4b7ea
  • Note that this release explicitly states that it is not published to PyPI.

4. Install the wheel 📄 Based on official documentation (this is where we got stuck)

   .\.venv\Scripts\python.exe -m pip --isolated install --no-cache-dir .\skillspector-2.13.2-py3-none-any.whl

Usage

All the steps below are 📄 based on official documentation. We could not run them because installation failed.

1. Check the help output 📄

   .\.venv\Scripts\skillspector.exe --help

2. Run static analysis without a key 📄 You can provide a Git repository, URL, zip, folder, or single file.

   .\.venv\Scripts\skillspector.exe scan .\my-skill --no-llm

3. Save as JSON (Windows) 📄 Instead of --output, redirect stdout (screen output) to a trusted path.

   .\.venv\Scripts\skillspector.exe scan .\my-skill --no-llm --format json > .\report.json

4. Interpret the score 📄 Risk scoring explained

  • 0–20 SAFE
  • 21–50 CAUTION
  • 51–80 HIGH / DO NOT INSTALL
  • 81–100 CRITICAL / DO NOT INSTALL

5. Inspect the findings yourself 📄 Look beyond the score: check file and line locations, scan coverage, and any incomplete-analysis indicators.

Our Hands-on Results

Verification level: partial. Here is the sequence of events.

  • We opened and read 3 official URLs: GitHub, the release page, and the NVIDIA documentation.
  • The v2.13.2 release timestamp was 2026-10-28T14:19:21Z. It included 3 maintenance fixes to reduce false-positive incomplete-analysis reports.
  • The wheel download returned HTTP 200 and took 0.857 seconds. The Version in its internal METADATA was 2.13.2, and the hash matched.
  • Creating the venv succeeded.
  • The pip installation failed after 1.458 seconds with exit code 1. It could not find the boto3>=1.34.0 dependency offline. We did not bypass the command-line internet restrictions.
  • skillspector.exe was missing, so we could not run --help, check the version, or perform a sample scan.

NVIDIA's official documentation: Static vs Semantic Analysis, the --no-llm command, and review policy. Enlarged view, not a screenshot of the tool running. (Video still)

What differed from our expectations: We thought the official wheel alone would be enough for an offline installation. In practice, dependencies such as boto3 had to be downloaded separately.

One more hiccup: When we tried to open the failure log via file://, the browser blocked access to the local file. Instead, we read the actual log and displayed it enlarged in a separate viewer for the recording. The screen shows the original log text, not a terminal capture.

GitHub README, Trust model and data egress: no execution of skill code, data sent to LLMs, OSV dependency lookups even with --no-llm, and offline limitations. (Video still)

What we could not verify: We neither created nor ran clean and risky examples. As a result, we have no score comparisons, flagged lines, false-positive results, or scan timings. Figures circulating on social media, such as "49 points in 8 seconds," are not our measurements. We saw approximately 23.9k stars on the repository page (latest commit: November 2, 2026), but did not verify the exact count or X view counts.

The research cited in the README also deserves a note. Of 42,447 total skills, 31,132 were actually analyzed; vulnerabilities were reportedly found in 26.1%, and patterns suspected to be malicious in 5.2%. These are not confirmed-malicious rates, and we did not independently recheck the original study. The pattern counts also differ: 71 in the README and 68 in NVIDIA's documentation.

Common Problems

  • Installation fails because boto3 cannot be found: Internet access is required to download dependencies. --no-index will not work.
  • skillspector.exe is missing: This means installation did not finish. Review the log from step 4.
  • --output does not work on Windows: This is a limitation documented in the README. Save stdout using >.
  • Python version error: v2.13.2 accepts only 3.12–3.14.
  • "Does --no-llm mean completely offline?": No. OSV.dev lookups may still occur.

To be clear about this experiment's limits: we made 1 installation attempt and ran 0 scans. We therefore could not evaluate the tool's detection performance at all. The attempt is also documented in a Short.
