What to Check Before Starting

  • Cost
  • OpenCode is open source (anyone can view its code). It uses the MIT license.
  • The version check and help command we ran did not require an account, a personal API key (a key for accessing an external AI service), payment, or registration.
  • OpenCode Go is an optional subscription costing 10 dollars per month. It is separate from installing OpenCode. We did not use it this time.
  • According to the official documentation, using only local models without selecting cloud models or Go incurs no API usage fees. Electricity, hardware costs, and each model's license and performance need to be considered separately.
  • Operating system (OS)
  • The OpenCode desktop app supports Windows x64/ARM64, macOS(Intel/Apple Silicon), and Linux(deb/rpm/AppImage).
  • The OpenCode v2 documentation states, "Windows package managers are not supported". This means Windows package managers (tools that install programs through commands) are not supported. It does not mean desktop installers are unavailable.
  • Ollama requirements for Windows: Windows 10 22H2 or later (Home/Pro), at least 4GB of installation space, plus separate storage for models.
  • What local AI requires 📄 Based on official documentation
  • You need a model downloaded in advance and a local Ollama API.
  • OpenCode requires a context length of 64K or more. Context length is the amount of text the AI can hold in memory at once.
  • Model memory usage (RAM/VRAM) varies by model and configuration. We did not measure it.
  • A caution about company code: We did not verify that "code never leaves the PC." Check plugins (add-on features), web tools, cloud model selections, and your company's security policies separately.

How to Install

To avoid changing our PC's settings, we used an isolated folder (a separate test folder kept apart from everything else).

1. Download the official ZIP ✅ Tested firsthand

  • Download opencode-windows-x64.zip from the v2.2.5 release page (the page distributing the new version) and save it in the downloads folder.
  • Success check: The file size is 121,962,397 bytes. Our download took 5.307 seconds.
  • If you get stuck: The file list (Assets) may take time to appear. We saw the link after collapsing and expanding the list.

3. Run the version and help commands ✅ Tested firsthand

  • Success check: The first line shows opencode v2.2.5, and the exit code is 0 (0 means the program exited normally). The version check took 15.642 seconds, and help took 0.150 seconds. These are not times for AI to fix code.

No global installation (installation across the PC) or administrator privileges were needed.

How to Use It

From here on, every step was checked only against official documentation. We did not run these steps ourselves.

1. Install Ollama and prepare a model 📄 Based on official documentation

  • Install Ollama and download a model in advance. The Windows installer is OllamaSetup.exe. The example command in the OpenCode v2 provider documentation is ollama pull qwen3:8b, but this is only an official example, not a recommendation that it suits our PC.
  • Note: A standard installation runs in the background (stays active out of sight) and changes PATH (registers command locations). This is why we did not install it.

2. Connect OpenCode 📄 Based on official documentation

  • The Ollama integration documentation provides the ollama launch opencode command. It explains that OpenCode reads projects, edits files, and runs commands.
ollama launch opencode
  • This is an integration command used after Ollama is already installed. We did not verify that it connects automatically and works correctly with v2.2.5.

3. Set the context length to 64K or more 📄 Based on official documentation

  • Move the context length slider in the Ollama app settings to 64k or higher. The documentation does not provide the exact menu or button names, so we have not listed them.
  • After the model loads, check the actual value in the CONTEXT column of ollama ps. This value cannot be guaranteed if there is insufficient memory.

This is where we got stuck.

  • The Ollama command was not available on the PC, and the connection to the model server at localhost:11434 (the gateway to AI on our PC) was refused.
  • Large model downloads, permanent installations, and system setting changes were outside the scope of this test, so we did not do them. We also did not turn off Wi-Fi or change the firewall.
  • The two official documents used different configuration formats. The Windows tab in the Ollama documentation uses npm install -g opencode-ai and provider/npm/options. The OpenCode v2 provider documentation uses @opencode/cli and providers/package/settings.
  • We also ran past our deadline. For Alibaba Open Code Review, our fallback candidate, we only read the README (documentation).

Some things also differed from what we expected. On the first download attempt, entering a relative URL caused an address resolution error. Switching to the full URL allowed the download to work. The browser also blocked opening a file on our PC (file://), so we switched to a temporary page displaying the actual output log and captured that instead. Common Sticking Points

  • The Assets list is not visible → Try collapsing and expanding the list.
  • Download URL error → Use the full URL rather than a relative URL.
  • Installation through a Windows package manager does not work → The v2 documentation says this is unsupported. Use the official standalone CLI or desktop app.
  • The connection to localhost:11434 is refused → This means no response was received from that address. Ollama may be missing or not running. If you changed the address or port, check that address instead. In our case, the Ollama command itself was unavailable.
  • The configuration examples differ between documents → Refer to the documentation for the OpenCode version you are using.

Conclusion

We were able to download and run the OpenCode v2.2.5 Windows CLI without an account or payment. However, we have not yet demonstrated the central goal of this article: "Disconnect the internet and code with AI on our PC." Next time, we will try again in an approved, isolated environment with Ollama, a 64K context setting, and a dummy example.
