Have you heard of Jev, the AI said to be '200× faster and 400× cheaper'? We wanted to find out whether that was true, so we gave Jev and 5 other AI models the same 30 fictional customer inquiries and measured their speed, cost, and accuracy ourselves. This article includes all 30 inquiries, the correct answers, and the measurement code so you can repeat the test.

We took these measurements ourselves on the morning of November 2, 2026, using one Windows 11 PC, a home internet connection in Korea, and API accounts we already used. This test was not sponsored.

What Is Jev? (A Simple Explanation)

Typical AI tools (ChatGPT, Claude, Gemini) write text for you. An easy way to think of Jev is as an AI that only answers multiple-choice questions. Give it a set of choices, and it selects one and returns the probability that each choice is correct. It cannot hold conversations or write text. (📄 Documentation: TypeSafe calls this kind of model a 'System One model'.)

  • Price: $0.042 per 1 million input tokens; output is free (📄 docs.typesafe.ai/models, checked 11/02)
  • Response time stated on the official blog: 0.07~0.5 seconds (📄 TypeSafe blog)

Models page in TypeSafe’s official documentation (captured 11/02): $0.042 per 1 million input tokens, free output

How Did We Measure It? (Conditions Kept Consistent)

  1. We wrote 30 inquiries ourselves. They are fictional and contain no real customer information: 15 easy questions, 10 medium questions mixing two issues, and 5 hard questions involving sarcasm, typos, or long messages.
  1. We fixed the choices (labels) at 5. Shipping / Refunds & exchanges / Payment errors / Account & login / Other.
  1. We finalized the correct answers in a file before the experiment. We displayed the answer file’s fingerprint-like value (SHA-256 hash) on screen at the start, then checked that it was unchanged afterward. Value: 7942a7f8828561e1dedb03c27352ead41e4da1feae38cde98729d53293c0efc0 (Identical before and after ✅)
  1. We gave every model the same instructions and choice descriptions. One call per inquiry, processed sequentially (no concurrent requests).
  1. For the 4 small models (including Jev), we ran all 30 questions 3 times. We changed both the model order and question order each round, and excluded the first call (the warm-up) from the results. → 90 calls per model
  1. We separately ran all 30 questions once on each of the 2 large models (GPT-6.1 Sol and Claude Fable 5.1), and measured another 30 Jev calls during the same period.
  1. Time was measured from immediately before sending the request until the full response arrived (including the round trip from Korea to each company’s servers). Cost was calculated as the actual token counts reported in the response × official rates.

Every model achieved a perfect score. We saw no evidence that 'faster means more errors' on these 30 questions, but this also means the questions were too easy to distinguish differences in accuracy.

Jev returns probabilities along with its answer. Its least confident inquiry was M06: "I reached the order confirmation screen, but there’s nothing in my order history. All I received was a card payment notification." It assigned 84~87% to Payment errors and 10~13% to Other, and chose the correct answer (Payment errors) in all 3 runs. This could be used to prioritize low-confidence inquiries for human review (you need to validate the probability threshold using your own Korean-language inquiries first).

Repeat the Test on Your PC (For Beginners)

You’ll need a Windows PC, Python, and API keys for the companies whose models you want to compare. We used keys we had already created. We have not checked whether TypeSafe is currently accepting new sign-ups.

  1. Check whether Python is installed. Open PowerShell from the Start (시작) menu and enter python --version. If you see text starting with Python 3., you’re ready! If not, install Python from python.org and open a new window.
  1. Create a folder. For example, create a jev-test folder on your desktop. In PowerShell, navigate to it with cd $HOME\Desktop\jev-test.
  1. Save 2 files in that folder. From the 'Download Files' section below, get items.py (30 inquiries and correct answers) and bench_public.py (measurement code).
  1. Set your API keys for that window only. Example: $env:TYPESAFE_API_KEY="여기에 키" (replace the Korean text with your key; for OpenAI, use OPENAI_API_KEY; for Gemini, GEMINI_API_KEY; for Claude, ANTHROPIC_API_KEY). The keys disappear when you close the window, keeping them safe. Models from companies for which you have no key will simply show 'Call failed (호출실패)'; the other models will still run.
  1. Run a single-call test. python bench_public.py --probe → If you see one line per model showing Shipping (배송), it worked!
  1. Run the main measurements. python bench_public.py --run → 4 models × 30 questions × 3 rounds = 360 calls (ours took about 4 minutes). When it finishes, the results folder will contain results.csv (one record per line) and summary.json (summary).
  1. Try your own inquiries: Replace the inquiries and correct answers in items.py with ones relevant to your work. Be sure to finalize the answers before running the test.

Common Problems and Fixes

  • Korean characters are garbled → Enter chcp 65001 in PowerShell first.
  • HTTP 401 → The key is incorrect or contains spaces. Check the text inside the quotation marks.
  • temperature is deprecated with Claude → The latest Claude models do not accept temperature. It has already been removed from the public code. (✅ Encountered firsthand)
  • tool_choice … not supported with Claude Fable → Use structured output (output_config) instead of forced tool calling. This is already reflected in the public code. (✅ Encountered firsthand)
  • Your timings are longer than ours → Results vary with your connection, time of day, and server location. That’s why measuring in your own environment matters.

Limitations, Honestly Stated

  • We tested just one task—customer inquiry classification—with only 30 questions.
  • Every model achieved a perfect score, so we could not determine which was more accurate.
  • Model settings: GPT-6 Luna had reasoning off, Gemini used minimal thinking, and Claude Haiku and the two large models used defaults. Changing the settings may change the timings.
  • We did not use Jev’s 'multiple questions in one request' feature (every model made one call per inquiry).
  • Costs are calculated values. We have not yet checked the billed amounts.
  • These results come from one test session on the morning of November 2, using one PC and one internet connection in Korea.

So, When Is Jev a Good Fit?

  • ✅ When you need to handle many tasks quickly that involve choosing one option (classification, routing, or checks)
  • ✅ If you currently classify inquiries with an expensive large model, the cost difference is substantial (35~330× in this test)
  • △ If you already use a cheap small model, the difference was around 2~5×
  • ❌ Tasks requiring writing, conversation, or explanations (it only selects an option)
  • 👉 Before switching, test it with your own inquiries first
